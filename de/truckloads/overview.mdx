## Wo Sie beginnen

Das Dashboard von Komplettladungen ist der Überblick. Es kann aktuelle Transportsummen, neueste Transportaktualisierungen und die Performance eines Zeitraums zeigen. Siehe [Das Dashboard verstehen](/de/start/dashboard).

Vom Dashboard aus können Sie öffnen:

- Einen [Transport in der Sendungsliste](/de/truckloads/shipments)
- Das [Detail eines Transports](/de/truckloads/shipment-detail)
- Den [Performance-Bericht](/de/truckloads/performance), wenn dieser Bericht angezeigt wird

<Info>
  Sie können im Portal keine Komplettladung anlegen. Komplettladungen nutzt nicht die Claim- und Ticketformulare von Pakete oder Paletten. Wenn ein Transport fehlt, prüfen Sie zuerst Auftragsnummer, Abgangsort, Bestimmungsort und Datumsbereich. Folgen Sie danach [Eine Sendung wird nicht gefunden](/de/support/shipment-not-found).
</Info>
