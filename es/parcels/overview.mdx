Use **Paquetes** para envíos de paquetes de salida y para devoluciones. No use el espacio de trabajo de Palets o de Cargas completas, ni el seguimiento público de palets, para un envío de Paquetes.

## Por dónde empezar

El dashboard de Paquetes es la visión general. Puede mostrar totales recientes de envíos, últimos envíos, últimas devoluciones, reclamaciones abiertas, tickets abiertos y un resumen del nivel de servicio. Consulte [Entienda el dashboard](/es/start/dashboard).

Desde el dashboard puede abrir:

- La [lista de envíos](/es/parcels/shipments)
- Una [devolución](/es/parcels/returns)
- Una [reclamación](/es/parcels/claims) o un [ticket](/es/parcels/tickets)
- El [informe de rendimiento](/es/parcels/performance) de un período seleccionado, cuando se muestre ese informe

<Info>
  No puede crear un envío en el portal. Si falta un paquete, compruebe primero el número de pedido y el rango de fechas. Después siga [No se encuentra un envío](/es/support/shipment-not-found).
</Info>
