El portal solo puede mostrar los eventos que ha recibido. Una pausa entre actualizaciones no siempre significa que el envío se haya detenido.

## Compruebe estos puntos

1. Confirme el producto: Paquetes, Palets o Cargas completas.
2. Confirme el número de pedido y, para palets, el código de barras. Para una carga completa, confirme también el origen, el destino y la matrícula.
3. Actualice la página y quite los filtros que puedan ocultar la fila.
4. Para un envío de Paquetes, lea el estado agrupado en [Envíos de Paquetes](/es/parcels/shipments).
5. Para un palet, lea la línea de tiempo del código de barras en [Detalles del paquete de Palets](/es/pallets/package-detail). El seguimiento público también se actualiza aproximadamente cada 30 segundos.
6. Para una carga completa, lea la última actualización en [Envíos de Cargas completas](/es/truckloads/shipments) y la línea de tiempo de paradas en [Revise una carga completa](/es/truckloads/shipment-detail).
7. Para una devolución, use [Devoluciones de Paquetes](/es/parcels/returns). Los eventos de recogida o recepción que faltan no significan que la devolución esté completa.

Si el estado sigue pareciendo incorrecto, reúna el último evento que pueda ver, la actualización que esperaba y la hora en que lo comprobó. Para Paquetes o Palets, cree **un** ticket. Para Cargas completas, [póngase en contacto con Support](/es/support/contact).

No vuelva a crear el envío y no abra un segundo ticket para los mismos códigos de barras.
