A lista de envios de paletes é a lista de trabalho com sessão iniciada para movimentos de paletes. Utilize-a quando já tiver um número de encomenda ou um código de barras.

<Frame caption="Captura de ecrã necessária — substitua `/pallet-shipments`. Oculte expedidor e destino.">
  <img src="/images/screenshot-placeholder.svg" alt="Marcador de posição para a lista de envios de paletes" />
</Frame>

## O que pode fazer

- Filtrar por data, estado, expedidor ou destino
- Ordenar e percorrer as páginas
- Abrir a encomenda ou o volume
- Ativar ou desativar as notificações de estado
- Transferir uma etiqueta de envio quando a ação for apresentada

## Colunas da lista

Cada linha pode incluir:

- Data da encomenda
- Número de encomenda
- Código de barras
- Expedidor
- Destino
- Estado
- Controlos de notificação
- Ação de etiqueta de envio

Uma encomenda pode ter mais do que um código de barras. Confirme o número de encomenda e o código de barras antes de continuar.

## Encontrar uma palete

<Steps>
  <Step title="Abrir Paletes">Inicie sessão e abra o espaço de trabalho Paletes.</Step>
  <Step title="Abrir a lista de envios">Vá à lista de envios de paletes.</Step>
  <Step title="Definir os filtros">Utilize data, estado, expedidor ou destino, juntamente com o número de encomenda ou o código de barras.</Step>
  <Step title="Abrir o registo">Abra a encomenda para o envio completo, ou o volume para um código de barras.</Step>
</Steps>

As contas de distribuidor podem ver apenas destinos com que têm autorização para trabalhar.

<Info>
  Se só precisar do progresso e não tiver início de sessão, utilize [Seguir uma palete sem iniciar sessão](/pt/pallets/public-tracking).
</Info>
