La lista de envíos de Paquetes con sesión iniciada es el lugar principal para revisar un paquete de salida. El portal no usa una página pública de seguimiento aparte para Paquetes.

<Frame caption="Captura de pantalla necesaria — sustituya una fila inspeccionada de `/shipments`. Enmascare nombres y direcciones.">
  <img src="/images/screenshot-placeholder.svg" alt="Marcador de posición para la información de un envío de Paquetes" />
</Frame>

## Qué comprobar

Desde la lista, confirme:

1. Número de pedido
2. Cliente y destino
3. Valor de track and trace
4. Transportista
5. Fecha de pedido
6. Último estado

Abra el envío desde la lista cuando necesite inspeccionar el registro seleccionado. Use solo la información que muestra el portal. No dé por hechos los datos de remitente, destinatario o comprobante de entrega si no están en pantalla.
