## Compruebe estos puntos

1. Confirme que está en **Paquetes**, **Palets** o **Cargas completas**, y no en otro espacio de trabajo.
2. Busque por el número de pedido completo.
3. Para palets, busque también por el código de barras o el número de seguimiento completo.
4. Para una carga completa, compruebe también el origen, el destino y la matrícula.
5. En [envíos de Paquetes](/es/parcels/shipments) o [Envíos de Cargas completas](/es/truckloads/shipments), amplíe el rango de fechas.
6. Para una devolución, use [Devoluciones de Paquetes](/es/parcels/returns). Las devoluciones no están en la lista de salida.
7. Para un pedido de Palets no confirmado, compruebe [Pedidos Incoming](/es/pallets/incoming-orders).
8. Si solo necesita el progreso de un palet, pruebe el [seguimiento público de palets](/es/pallets/public-tracking).

Si el registro sigue sin aparecer, reúna el tipo de producto, el número de pedido y cualquier código de barras, número de seguimiento o matrícula. Para Paquetes o Palets, cree un ticket. Para Cargas completas, [póngase en contacto con Support](/es/support/contact). Consulte [Información que Support necesita](/es/support/required-information).
