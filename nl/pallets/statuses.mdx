Statussen in Pallets komen uit de palletstatushistorie. Het portaal zet die gebeurtenissen om naar de namen die u op de lijst en op de pakkettijdlijn ziet.

Lees de laatste gebeurtenis op de [pakketpagina](/nl/pallets/package-detail). Die barcodetijdlijn is de plek om de voortgang te volgen.

## Planningsstatussen

Deze statussen worden gebruikt in de ingelogde planningsworkflow:

| Status | Wat het in het portaal betekent |
| --- | --- |
| Incoming | De order heeft nog geen laatste status en verschijnt op de lijst Incoming |
| Ready To Ship | U heeft de zending bevestigd in Incoming Orders |
| Shipment Communicated to Carrier | De zending is doorgegeven aan de vervoerder. Revert kan na dit punt worden geblokkeerd |
| Order Cancelled | De order is geannuleerd |

## Namen voor beweging en levering die u kunt zien

Deze namen kunnen op de lijst en op de pakkettijdlijn verschijnen:

| Status | Wat het in het portaal betekent |
| --- | --- |
| Picked Up | De pallet is opgehaald |
| Arrival HUB | De pallet is aangekomen in een hub |
| In Transit | De pallet is onderweg tussen locaties |
| Out for Delivery | De pallet is onderweg voor de laatste bezorging |
| Delivered | De pallet is afgeleverd |
| Delivered, Partially Missing | De pallet is afgeleverd, maar een deel van de goederen ontbreekt |
| Delivered on Appointment | De pallet is afgeleverd op een afgesproken afspraak |
| Delivered, Partly Delivered | De pallet is slechts deels afgeleverd |
| Damaged | De pallet of de goederen zijn als beschadigd gemeld |
| Refused | De levering is geweigerd |
| Address closed | Het afleveradres was gesloten |
| Returned | De pallet wordt geretourneerd of is geretourneerd |
| On hold | De zending staat on hold |
| Missing in network | De pallet ontbreekt in het netwerk van de vervoerder |

## Statussen zijn geen supportzaken

Een pallet kan **Delivered** tonen terwijl een [claim](/nl/pallets/claims) nog openstaat. Een planningsstatus kan er normaal uitzien terwijl een [ticket](/nl/pallets/tickets) wordt behandeld.

Als de laatste gebeurtenis ontbreekt of er verkeerd uitziet, maak de zending niet opnieuw aan. Volg [Een zendingsstatus is niet bijgewerkt](/nl/support/status-not-updated) en vermeld het ordernummer en de barcode.
