El informe de rendimiento de Cargas completas es una página de Cargas completas con sesión iniciada. Es para un período de informe, no para un solo transporte.

<Frame caption="Captura de pantalla necesaria — sustituya `/ftl-performance-report` con el período seleccionado visible. Enmascare los nombres de empresa y de ruta.">
  <img src="/images/screenshot-placeholder.svg" alt="Marcador de posición para el informe de rendimiento de Cargas completas" />
</Frame>

## Abra el informe

<Steps>
  <Step title="Abra Cargas completas">Inicie sesión y abra el espacio de trabajo de Cargas completas.</Step>
  <Step title="Abra el informe de rendimiento">Use el informe desde el dashboard de Cargas completas cuando se muestre.</Step>
  <Step title="Elija el período">Ajuste el rango de fechas que desea revisar.</Step>
  <Step title="Restrinja el alcance">Use los filtros de origen, destino u otros filtros que se muestren en la página. Un filtro de cliente aparece solo en algunas cuentas de administrador.</Step>
  <Step title="Lea los resultados">Compruebe los totales, las tablas por país o por ruta y los transportes agrupados.</Step>
  <Step title="Exporte">Exporte el informe que está en pantalla, incluidos los filtros activos.</Step>
</Steps>

El informe necesita el módulo Cargas completas. Si no puede abrirlo, es posible que su empresa no tenga esa página.

<Info>
  Use [Envíos de Cargas completas](/es/truckloads/shipments) cuando necesite un transporte concreto. Este informe es para un período, no para una sola carga completa.
</Info>
