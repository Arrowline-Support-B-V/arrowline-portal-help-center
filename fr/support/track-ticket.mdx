Ouvrez la liste des tickets dans le même espace de travail que celui où vous avez créé le ticket, puis sélectionnez le ticket.

<Frame caption="Capture d'écran requise — remplacez une conversation de ticket. Masquez les commentaires et les fichiers.">
  <img src="/images/screenshot-placeholder.svg" alt="Espace réservé pour une conversation de ticket de support" />
</Frame>

La conversation peut afficher :

- L'historique du ticket
- Les commentaires
- Les pièces jointes
- L'expédition, la commande ou le code-barres lié lorsqu'il est disponible

Répondez dans cette conversation. N'ouvrez pas un second ticket pour les mêmes codes-barres.

Voir [Tickets Colis](/fr/parcels/tickets) ou [Tickets Palettes](/fr/pallets/tickets).
