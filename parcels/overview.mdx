Use **Parcels** for outbound parcel shipments and for returns. Do not use the Pallets or Truckloads workspace, or public pallet tracking, for a parcel.

## Where to start

The Parcel dashboard is the overview. It can show recent shipment totals, latest shipments, latest returns, open claims, open tickets and a service-level summary. See [Understand the dashboard](/start/dashboard).

From the dashboard you can open:

- The [shipment list](/parcels/shipments)
- A [return](/parcels/returns)
- A [claim](/parcels/claims) or [ticket](/parcels/tickets)
- The [performance report](/parcels/performance) for a selected period, when that report is shown

<Info>
  You cannot create a shipment in the portal. If a parcel is missing, check the order number and date range first. Then follow [A shipment cannot be found](/support/shipment-not-found).
</Info>
