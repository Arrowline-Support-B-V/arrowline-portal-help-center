El informe de rendimiento de Paquetes es una página de Paquetes con sesión iniciada. Es para un período de informe, no para un solo envío.

<Frame caption="Captura de pantalla necesaria — sustituya `/report/detail` con el período seleccionado visible. Enmascare los nombres de empresa.">
  <img src="/images/screenshot-placeholder.svg" alt="Marcador de posición para el informe de rendimiento de Paquetes" />
</Frame>

## Abra el informe

<Steps>
  <Step title="Abra Paquetes">Inicie sesión y abra el espacio de trabajo de Paquetes.</Step>
  <Step title="Abra el informe de rendimiento">Use el informe desde el dashboard de Paquetes cuando se muestre.</Step>
  <Step title="Elija el período">Ajuste la fecha o el mes que desea revisar.</Step>
  <Step title="Lea los resultados">Compruebe los totales de estado, las tarjetas de rendimiento, el gráfico y la tabla por país.</Step>
  <Step title="Descargue un PDF">Exporte el informe que está en pantalla, incluido el período seleccionado.</Step>
</Steps>

El informe necesita el módulo Paquetes. Si no puede abrirlo, es posible que su empresa no tenga esa página.

<Info>
  Use [Envíos de Paquetes](/es/parcels/shipments) cuando necesite un pedido concreto. Este informe es para un período, no para un solo paquete.
</Info>
