description: "Senden Sie ein vollständiges Ticket aus Pakete oder Paletten."
icon: "ticket"
---

Erstellen Sie das Ticket im selben Produkt wie die Sendung. Ein Ticket aus Pakete erscheint nicht in Paletten. Komplettladungen hat im Portal kein Ticketformular. Für eine Komplettladung [kontaktieren Sie Support](/de/support/contact) mit den Transportangaben.

<Frame caption="Screenshot erforderlich — ersetzen Sie `/tickets/add` oder `/pallet/tickets/add`. Blenden Sie Kennungen aus.">
  <img src="/images/screenshot-placeholder.svg" alt="Platzhalter für das Formular zum Erstellen eines Tickets" />
</Frame>

<Steps>
  <Step title="Öffnen Sie das passende Modul">Wählen Sie Pakete oder Paletten. Mischen Sie die beiden nicht. Nutzen Sie diese Formulare nicht für eine Komplettladung.</Step>
  <Step title="Öffnen Sie Tickets">Wählen Sie die Ticketliste und starten Sie ein neues Ticket.</Step>
  <Step title="Suchen Sie den Auftrag">Geben Sie die vollständige Auftragsnummer ein. Das Portal sperrt einen unbekannten Auftrag.</Step>
  <Step title="Wählen Sie die Barcodes">Wählen Sie mindestens eine track-and-trace-Nummer in Pakete oder einen Barcode in Paletten.</Step>
  <Step title="Wählen Sie die Art des Themas">Wählen Sie eine Kategorie und danach eine Unterkategorie.</Step>
  <Step title="Beschreiben und senden">Schreiben Sie einen Kommentar, hängen Sie Dateien an, falls nötig, und senden Sie einmal. Dateien in Pakete können jeweils bis zu 50 MB groß sein.</Step>
</Steps>

Wenn jeder Barcode zum Auftrag bereits ein Ticket hat, öffnen Sie stattdessen dieses Ticket.

Die vollständigen Produktschritte finden Sie unter [Tickets in Pakete](/de/parcels/tickets) oder [Tickets in Paletten](/de/pallets/tickets). Bei Schaden, Fehlmenge oder Verlust nutzen Sie einen Claim, kein zweites Ticket.
