Nutzen Sie **Paletten** für Palettenaufträge und Pakete. Suchen Sie eine Palette nicht im Arbeitsbereich Pakete oder Komplettladungen.

<CardGroup cols={2}>
  <Card title="Ohne Anmeldung verfolgen" icon="location-dot" href="/de/pallets/public-tracking">

  </Card>
  <Card title="Eingehende Aufträge" icon="inbox" href="/de/pallets/incoming-orders">

  </Card>
  <Card title="Sendungsliste" icon="list" href="/de/pallets/shipments">

  </Card>
  <Card title="Claims und Tickets" icon="life-ring" href="/de/pallets/claims">

  </Card>

## Wo Sie beginnen

Das Dashboard von Paletten ist der Überblick. Es kann aktuelle Palettensummen, neueste Sendungen, Incoming orders, Claims, Tickets und Performance-Ergebnisse zeigen. Siehe [Das Dashboard verstehen](/de/start/dashboard).

Distributor-Konten sehen möglicherweise nur Palettendatensätze für zulässige Bestimmungsländer. Manche Administratorkonten können das Unternehmen auf dem Dashboard ändern.

<Info>
  Die öffentliche Verfolgung braucht keine Anmeldung und zeigt keine Aktionen für Incoming orders, Labels, Claims oder Tickets. Nutzen Sie für diese Arbeit den angemeldeten Arbeitsbereich.
</Info>
