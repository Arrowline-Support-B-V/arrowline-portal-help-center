## Par où commencer

Le tableau de bord Palettes est la vue d'ensemble. Il peut afficher les totaux de palettes récents, les dernières expéditions, les incoming orders, les réclamations, les tickets et les résultats de performance. Voir [Comprendre le tableau de bord](/fr/start/dashboard).

Les comptes distributeur peuvent ne voir que les enregistrements de palettes pour les pays de destination autorisés. Certains comptes administrateur peuvent changer l'entreprise affichée sur le tableau de bord.

<Info>
  Le suivi public ne nécessite pas de connexion et n'affiche pas les actions incoming orders, les étiquettes, les réclamations ni les tickets. Utilisez l'espace de travail une fois connecté pour ce travail.
</Info>
