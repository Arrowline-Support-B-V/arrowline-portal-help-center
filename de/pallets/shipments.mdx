Die Sendungsliste von Paletten ist die Arbeitsliste nach der Anmeldung für Palettenbewegungen. Nutzen Sie sie, wenn Sie bereits eine Auftragsnummer oder einen Barcode haben.

<Frame caption="Screenshot erforderlich — ersetzen Sie `/pallet-shipments`. Blenden Sie Versender und Bestimmungsort aus.">
  <img src="/images/screenshot-placeholder.svg" alt="Platzhalter für die Sendungsliste von Paletten" />
</Frame>

## Was Sie tun können

- Nach Datum, Status, Versender oder Bestimmungsort filtern
- Sortieren und durch Seiten blättern
- Den Auftrag oder das Paket öffnen
- Statusbenachrichtigungen ein- oder ausschalten
- Ein Versandlabel herunterladen, wenn die Aktion angezeigt wird

## Spalten in der Liste

Jede Zeile kann enthalten:

- Auftragsdatum
- Auftragsnummer
- Barcode
- Versender
- Bestimmungsort
- Status
- Steuerungen für Benachrichtigungen
- Aktion für das Versandlabel

Ein Auftrag kann mehr als einen Barcode haben. Prüfen Sie Auftragsnummer und Barcode, bevor Sie weitergehen.

## Eine Palette finden

<Steps>
  <Step title="Öffnen Sie Paletten">Melden Sie sich an und öffnen Sie den Arbeitsbereich Paletten.</Step>
  <Step title="Öffnen Sie die Sendungsliste">Gehen Sie zur Sendungsliste von Paletten.</Step>
  <Step title="Setzen Sie die Filter">Nutzen Sie Datum, Status, Versender oder Bestimmungsort zusammen mit der Auftragsnummer oder dem Barcode.</Step>
  <Step title="Öffnen Sie den Datensatz">Öffnen Sie den Auftrag für die gesamte Sendung oder das Paket für einen Barcode.</Step>
</Steps>

Distributor-Konten sehen möglicherweise nur Bestimmungsorte, mit denen sie arbeiten dürfen.

<Info>
  Wenn Sie nur den Fortschritt brauchen und keine Anmeldung haben, nutzen Sie [Eine Palette ohne Anmeldung verfolgen](/de/pallets/public-tracking).
</Info>
