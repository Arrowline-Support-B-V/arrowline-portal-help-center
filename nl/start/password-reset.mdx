Gebruik het opnieuw instellen van het wachtwoord wanneer u niet kunt inloggen en een nieuw portaalwachtwoord nodig heeft. De flow heeft drie stappen: een reset aanvragen, de code uit uw e-mail invoeren en daarna een nieuw wachtwoord opslaan.

## Uw wachtwoord opnieuw instellen

<Steps>
  <Step title="Open Forgot password">Selecteer op de [inlogpagina](/nl/start/sign-in) de link Forgot password.</Step>
  <Step title="Vul uw geregistreerde e-mailadres in">Vraag het portaal om een resetcode naar dat adres te sturen.</Step>
  <Step title="Vul de resetcode in">Open de e-mail en typ de code op de verificatiestap. De code is één uur geldig.</Step>
  <Step title="Kies een nieuw wachtwoord">Vul het nieuwe wachtwoord twee keer in. Het moet voldoen aan de wachtwoordregels hieronder.</Step>
  <Step title="Log opnieuw in">Na een geslaagde reset brengt het portaal u terug naar de inlogpagina. Log in met het nieuwe wachtwoord.</Step>
</Steps>

## Wachtwoordregels

Uw nieuwe wachtwoord moet aan alles hieronder voldoen:

- Minimaal 8 tekens
- Eén hoofdletter
- Eén kleine letter
- Eén cijfer
- Eén toegestaan speciaal teken: `! @ # $ % ^ & * ) ( + = . _ -`

De twee wachtwoordvelden moeten overeenkomen voordat u het nieuwe wachtwoord kunt opslaan.

<Warning>
  Stuur uw wachtwoord, resetcode of een screenshot van de e-mailverificatie niet naar Support. Als de code is verlopen, start de reset opnieuw vanaf de inlogpagina.
</Warning>

## Als de reset niet werkt

1. Controleer of u het e-mailadres gebruikt dat voor het portaal is geregistreerd.
2. Controleer de map spam of ongewenste e-mail op de resetmail.
3. Vraag een nieuwe code aan als er meer dan één uur is verstreken.
4. Volg [Ik kan niet inloggen](/nl/support/cannot-sign-in) als u nog steeds geen toegang tot het portaal heeft.
