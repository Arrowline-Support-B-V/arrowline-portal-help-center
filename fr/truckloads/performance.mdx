Le rapport de performance Chargements complets est une page Chargements complets une fois connecté. Il concerne une période de reporting, pas un seul transport.

<Frame caption="Capture d'écran requise — remplacez `/ftl-performance-report` avec la période sélectionnée visible. Masquez les noms d'entreprise et d'itinéraire.">
  <img src="/images/screenshot-placeholder.svg" alt="Espace réservé pour le rapport de performance Chargements complets" />
</Frame>

## Ouvrir le rapport

<Steps>
  <Step title="Ouvrez Chargements complets">Connectez-vous et ouvrez l'espace de travail Chargements complets.</Step>
  <Step title="Ouvrez le rapport de performance">Utilisez le rapport depuis le tableau de bord Chargements complets lorsqu'il est affiché.</Step>
  <Step title="Choisissez la période">Définissez la plage de dates que vous voulez consulter.</Step>
  <Step title="Restreignez le périmètre">Utilisez les filtres d'origine, de destination ou les autres filtres affichés sur la page. Un filtre client n'apparaît que pour certains comptes administrateur.</Step>
  <Step title="Lisez les résultats">Vérifiez les totaux, les tableaux par pays ou par itinéraire et les transports regroupés.</Step>
  <Step title="Exportez">Exportez le rapport affiché à l'écran, y compris les filtres actifs.</Step>
</Steps>

Le rapport nécessite le module Chargements complets. Si vous ne pouvez pas l'ouvrir, votre entreprise n'a peut-être pas cette page.

<Info>
  Utilisez [Expéditions Chargements complets](/fr/truckloads/shipments) lorsque vous avez besoin d'un transport individuel. Ce rapport concerne une période, pas un seul chargement complet.
</Info>
