Filter gehören zu der Liste, die Sie gerade ansehen. Export lädt das gefilterte Ergebnis herunter, nicht jeden Datensatz im Portal.

## Eine Liste filtern

<Steps>
  <Step title="Öffnen Sie die richtige Liste">Nutzen Sie eine Liste in Pakete, Paletten oder Komplettladungen, keine Mischung aus Produkten.</Step>
  <Step title="Setzen Sie die Filter, die zu dieser Seite gehören">Nur die Steuerungen auf der Seite gelten für diese Liste.</Step>
  <Step title="Prüfen Sie die Ergebnisanzahl">Bestätigen Sie, dass die Anzahl der Zeilen noch zu der Arbeit passt, die Sie erledigen müssen.</Step>
  <Step title="Exportieren Sie die aktuelle Ansicht">Nutzen Sie Export, wenn die Seite das anbietet. Die Datei folgt den aktiven Filtern.</Step>
</Steps>

## Filter, mit denen Sie rechnen können

**Sendungen in Pakete** können Datums- und Statusfilter enthalten, zusammen mit den anderen operativen Filtern auf dieser Liste.

**Sendungen in Paletten** können Filter für Datum, Status, Versender und Bestimmungsort enthalten.

**Sendungen in Komplettladungen** können Filter für Datum, Abgangsort, Bestimmungsort und Status enthalten.

**Der Performance-Bericht für Komplettladungen** nutzt den Zeitraum und die Filter für Abgangsort, Bestimmungsort oder andere Filter, die auf dieser Seite aktiv sind. Export folgt demselben Umfang.

**Claims in Pakete und Paletten** können Filter für Status, Datum und Unternehmen enthalten, plus einen Datumsbereich.

**Tickets** können in der Ticketübersicht desselben Arbeitsbereichs gefiltert und exportiert werden.

Die Sendungsliste von Pakete startet mit einem begrenzten Datumsbereich. Erweitern Sie die Daten, bevor Sie entscheiden, dass eine Sendung fehlt.

<Info>
  Auf manchen Seiten können Sie Statusbenachrichtigungen für eine Sendung, einen Claim oder ein Ticket ein- oder ausschalten. Diese Alarmeinstellung ist getrennt von der Exportdatei.
</Info>

## Nach dem Export

Öffnen Sie die Datei und prüfen Sie, ob die Zeilenanzahl zur gefilterten Liste auf dem Bildschirm passt. Wenn nicht, behalten Sie die Filter bei, machen Sie einen Screenshot und folgen Sie [Portalfehler](/de/support/portal-errors).
