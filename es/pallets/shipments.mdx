La lista de envíos de Palets es la lista de trabajo con sesión iniciada para los movimientos de palets. Úsela cuando ya tenga un número de pedido o un código de barras.

<Frame caption="Captura de pantalla necesaria — sustituya `/pallet-shipments`. Enmascare remitente y destino.">
  <img src="/images/screenshot-placeholder.svg" alt="Marcador de posición para la lista de envíos de Palets" />
</Frame>

## Qué puede hacer

- Filtrar por fecha, estado, remitente o destino
- Ordenar y pasar de página
- Abrir el pedido o el paquete
- Activar o desactivar las notificaciones de estado
- Descargar una etiqueta de envío cuando se muestre la acción

## Columnas de la lista

Cada fila puede incluir:

- Fecha de pedido
- Número de pedido
- Código de barras
- Remitente
- Destino
- Estado
- Controles de notificación
- Acción de etiqueta de envío

Un pedido puede tener más de un código de barras. Confirme el número de pedido y el código de barras antes de continuar.

## Encuentre un palet

<Steps>
  <Step title="Abra Palets">Inicie sesión y abra el espacio de trabajo de Palets.</Step>
  <Step title="Abra la lista de envíos">Vaya a la lista de envíos de Palets.</Step>
  <Step title="Ajuste los filtros">Use fecha, estado, remitente o destino, junto con el número de pedido o el código de barras.</Step>
  <Step title="Abra el registro">Abra el pedido para el envío completo, o el paquete para un código de barras.</Step>
</Steps>

Las cuentas de distribuidor pueden ver solo los destinos con los que están autorizadas a trabajar.

<Info>
  Si solo necesita el progreso y no tiene acceso, use [Siga un palet sin iniciar sesión](/es/pallets/public-tracking).
</Info>
