Utilisez **Colis** pour les expéditions de colis sortantes et pour les retours. N'utilisez pas l'espace de travail Palettes ou Chargements complets, ni le suivi public des palettes, pour un colis.

## Par où commencer

Le tableau de bord Colis est la vue d'ensemble. Il peut afficher les totaux d'expéditions récents, les dernières expéditions, les derniers retours, les réclamations ouvertes, les tickets ouverts et un résumé du niveau de service. Voir [Comprendre le tableau de bord](/fr/start/dashboard).

Depuis le tableau de bord, vous pouvez ouvrir :

- La [liste des expéditions](/fr/parcels/shipments)
- Un [retour](/fr/parcels/returns)
- Une [réclamation](/fr/parcels/claims) ou un [ticket](/fr/parcels/tickets)
- Le [rapport de performance](/fr/parcels/performance) pour une période sélectionnée, lorsque ce rapport est affiché

<Info>
  Vous ne pouvez pas créer une expédition dans le portail. Si un colis manque, vérifiez d'abord le numéro de commande et la plage de dates. Suivez ensuite [Une expédition est introuvable](/fr/support/shipment-not-found).
</Info>
