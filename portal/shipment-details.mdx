Always confirm the order number, date and destination before you create a claim or ticket.

## Parcel information

The signed-in parcel shipment list is the main place to review a parcel. Each row can include:

- Order number
- Customer
- Destination
- Track and trace
- Carrier
- Ordered date
- Status

From the list you can inspect the selected shipment and turn status notifications on or off when that control is shown.

Returns are a separate parcel workflow. They do not appear as normal outbound shipments. Use [Parcel returns](/parcels/returns) for the return list, return detail and package detail.

This Help Center does not describe a separate public tracking page for parcels.

## Truckloads information

Open a truckload from the [Truckloads shipment list](/truckloads/shipments). The list row can include departure date, order number, origin, destination, stops, licence plate, status and last update.

The detail page can add:

- Transport facts
- The stop list
- Arrival and departure times
- Vehicle or carrier data when it is shown
- Status notifications for that transport

See [Review a truckload](/truckloads/shipment-detail).

## Pallet information

Signed-in pallet details are split by order and by package.

The **order** page can include:

- Order data
- Barcodes in the shipment
- Destination and delivery information
- Expected delivery, when available
- Status timeline

The **package** page is for one barcode. Open it from the order, or by searching that barcode.

Public pallet tracking shows a shorter view of the same kind of facts: order and barcode, destination, weight, carrier, expected delivery and the status timeline. See [Track a pallet without signing in](/pallets/public-tracking).

## What to check before you ask for help

1. Confirm you opened Parcels, Pallets or Truckloads, not another workspace.
2. Match the order number and, for pallets, the barcode. For a truckload, also match origin, destination and licence plate.
3. Read the latest status and the destination.
4. Note any related claim or ticket already shown on a parcel or pallet record.

Then continue to [Understand shipment statuses](/portal/statuses) or [Information Support needs](/support/required-information).
