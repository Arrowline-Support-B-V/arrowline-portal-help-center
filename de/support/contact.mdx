Nutzen Sie das Portal, wann immer Sie können, damit die Anfrage bereits den Sendungskontext enthält.

<CardGroup cols={2}>
  <Card title="Ticket in Pakete" icon="box" href="/de/parcels/tickets">
    Untersuchen Sie eine Verzögerung, eine fehlende Aktualisierung oder ein Portalproblem bei einer Paketsendung.
  </Card>
  <Card title="Ticket in Paletten" icon="boxes-stacked" href="/de/pallets/tickets">
    Untersuchen Sie einen Palettenauftrag, einen Barcode oder ein Portalproblem.
  </Card>
  <Card title="Claim in Pakete" icon="file-circle-exclamation" href="/de/parcels/claims">
    Melden Sie Schaden, Fehlmenge oder Verlust bei einer Paketsendung.
  </Card>
  <Card title="Claim in Paletten" icon="file-circle-exclamation" href="/de/pallets/claims">
    Melden Sie Schaden, Fehlmenge oder Verlust bei einer Palette.
  </Card>
  <Card title="Komplettladungen" icon="truck" href="/de/truckloads/overview">
    Verfolgen Sie einen Komplettladung. Komplettladungen hat kein Claim- oder Ticketformular.
  </Card>
</CardGroup>

<CardGroup cols={2}>
  <Card title="Ich kann mich nicht anmelden" icon="key" href="/de/support/cannot-sign-in">
    Klären Sie Anmeldung, Passwort-Reset oder fehlende Module.
  </Card>
  <Card title="Angaben, die Support braucht" icon="clipboard-list" href="/de/support/required-information">
    Sammeln Sie die Referenzen, bevor Sie senden.
  </Card>
</CardGroup>

Senden Sie weder Ihr Passwort noch den Reset-Code. Für Kontodokumente oder eine Änderung der Telefonnummer nutzen Sie [Ihr Konto verwalten](/de/start/account).
