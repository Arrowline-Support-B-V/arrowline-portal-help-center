## Vérifiez ces points

1. Confirmez que vous utilisez l'adresse e-mail enregistrée pour le portail.
2. Saisissez à nouveau votre mot de passe avec soin. Si la connexion échoue, le portail n'indique pas si l'adresse e-mail existe.
3. Utilisez [Réinitialiser votre mot de passe](/fr/start/password-reset) si vous avez oublié votre mot de passe.
4. Après une connexion réussie, consultez [Choisir votre flux de travail](/fr/start/choose-your-workflow). Vous ne voyez que les modules attribués à votre entreprise.
5. Si vous pouvez vous connecter mais que Colis ou Palettes manque, demandez à l'administrateur du portail de vérifier les modules de l'entreprise.

Si l'accès reste indisponible, contactez Support avec l'adresse e-mail que vous utilisez pour vous connecter. N'envoyez jamais le mot de passe ni le code de réinitialisation.

<Warning>
  Un lien enregistré n'ouvre pas un module qui n'est pas disponible pour votre compte.
</Warning>
