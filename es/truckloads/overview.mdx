## Por dónde empezar

El dashboard de Cargas completas es la visión general. Puede mostrar totales recientes de transportes, las últimas actualizaciones de transportes y el rendimiento del período. Consulte [Entienda el dashboard](/es/start/dashboard).

Desde el dashboard puede abrir:

- Un [transporte en la lista de envíos](/es/truckloads/shipments)
- El [detalle de un transporte](/es/truckloads/shipment-detail)
- El [informe de rendimiento](/es/truckloads/performance) cuando se muestre ese informe

<Info>
  No puede crear una carga completa en el portal. Cargas completas no usa los formularios de reclamación y de ticket de Paquetes o de Palets. Si falta un transporte, compruebe primero el número de pedido, el origen, el destino y el rango de fechas. Después siga [No se encuentra un envío](/es/support/shipment-not-found).
</Info>
