Use password reset when you cannot sign in and need a new portal password. The flow has three steps: request a reset, enter the code from your email, then save a new password.

## Reset your password

<Steps>
  <Step title="Open Forgot password">From the [sign-in page](/start/sign-in), select the Forgot password link.</Step>
  <Step title="Enter your registered email">Ask the portal to send a reset code to that address.</Step>
  <Step title="Enter the reset code">Open the email and type the code on the verification step. The code is valid for one hour.</Step>
  <Step title="Choose a new password">Enter the new password twice. It must meet the portal password rules below.</Step>
  <Step title="Sign in again">After a successful reset, the portal returns you to the sign-in page. Sign in with the new password.</Step>
</Steps>

## Password rules

Your new password must include all of the following:

- At least 8 characters
- One uppercase letter
- One lowercase letter
- One number
- One allowed special character: `! @ # $ % ^ & * ) ( + = . _ -`

The two password fields must match before you can save the new password.

<Warning>
  Do not send your password, reset code or email verification screenshot to Support. If the code has expired, start the reset again from the sign-in page.
</Warning>

## If reset does not work

1. Confirm that you are using the email address registered for the portal.
2. Check spam or junk folders for the reset email.
3. Request a new code if more than one hour has passed.
4. Follow [I cannot sign in](/support/cannot-sign-in) if you still cannot access the portal.
