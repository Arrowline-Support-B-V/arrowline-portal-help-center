Die Sendungsliste von Komplettladungen ist die zentrale Arbeitsliste für Komplettladungen. Sie zeigt die Transporte, die für Ihr Unternehmen verfügbar sind.

<Frame caption="Screenshot erforderlich — ersetzen Sie `/ftl-shipments`. Blenden Sie Abgangsort, Bestimmungsort und Kennzeichen aus.">
  <img src="/images/screenshot-placeholder.svg" alt="Platzhalter für die Sendungsliste von Komplettladungen" />
</Frame>

## Was Sie tun können

- Die Liste durchsuchen oder filtern
- Durch Seiten blättern
- Den letzten Status prüfen
- Einen Transport öffnen
- Statusbenachrichtigungen ein- oder ausschalten

## Spalten in der Liste

Jede Zeile kann enthalten:

- Abfahrtsdatum
- Auftragsnummer
- Abgangsort
- Bestimmungsort
- Stopps
- Kennzeichen
- Status
- Letzte Aktualisierung

Der Status, den Sie sehen, ist ein operativer Status in Komplettladungen wie Planned, In Transit oder Arrived. Siehe [Status in Komplettladungen](/de/truckloads/statuses).

## Einen Transport finden

<Steps>
  <Step title="Öffnen Sie Komplettladungen">Melden Sie sich an und öffnen Sie den Arbeitsbereich Komplettladungen.</Step>
  <Step title="Öffnen Sie die Sendungsliste">Gehen Sie zur Sendungsliste von Komplettladungen.</Step>
  <Step title="Setzen Sie den Datumsbereich">Erweitern Sie die Daten, wenn der Transport älter ist als der Zeitraum auf dem Bildschirm.</Step>
  <Step title="Suchen oder filtern">Nutzen Sie die Auftragsnummer und die Filter für Abgangsort, Bestimmungsort, Status oder andere Filter, die auf der Seite angezeigt werden.</Step>
  <Step title="Prüfen Sie die Zeile">Bestätigen Sie Abgangsort, Bestimmungsort, Kennzeichen und Datum, bevor Sie weitergehen.</Step>
</Steps>

<Warning>
  Eine Komplettladung ist keine Paketsendung und keine Palette. Die Liste von Pakete, die Liste von Paletten und die öffentliche Palettenverfolgung finden sie nicht.
</Warning>

Wenn der Transport weiterhin fehlt, folgen Sie [Eine Sendung wird nicht gefunden](/de/support/shipment-not-found).
