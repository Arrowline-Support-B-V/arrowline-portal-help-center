The portal can only show events it has received. A pause between updates does not always mean the shipment has stopped.

## Check these points

1. Confirm the product: Parcels, Pallets or Truckloads.
2. Confirm the order number and, for pallets, the barcode. For a truckload, also confirm origin, destination and licence plate.
3. Refresh the page and clear filters that could hide the row.
4. For a parcel, read the grouped status on [Parcel shipments](/parcels/shipments).
5. For a pallet, read the barcode timeline on [Pallet package details](/pallets/package-detail). Public tracking also refreshes about every 30 seconds.
6. For a truckload, read the last update on [Truckload shipments](/truckloads/shipments) and the stop timeline on [Review a truckload](/truckloads/shipment-detail).
7. For a return, use [Parcel returns](/parcels/returns). Missing collection or receipt events do not mean the return is complete.

If the status still looks wrong, collect the last event you can see, the update you expected and the time you checked. For Parcels or Pallets, create **one** ticket. For Truckloads, [contact Support](/support/contact).

Do not recreate the shipment and do not open a second ticket for the same barcodes.
