Chaque module auquel vous avez droit a son propre tableau de bord. Les données Colis, Palettes et Chargements complets ne sont pas mélangées sur un seul écran.

Après la connexion, le portail ouvre le premier module auquel vous avez droit. De là, vous pouvez passer aux autres modules affichés dans l'en-tête.

## Tableau de bord Colis

Ouvrez **Colis** lorsque vous avez besoin d'une vue d'ensemble de l'activité colis. Le tableau de bord peut afficher :

- Les totaux d'expéditions par statut opérationnel
- Les dernières expéditions de colis
- Les derniers retours
- Les réclamations Colis ouvertes
- Les tickets Colis ouverts
- Un résumé du niveau de service

De là, vous pouvez ouvrir la [liste des expéditions](/fr/parcels/shipments), un [retour](/fr/parcels/returns), une [réclamation](/fr/parcels/claims), un [ticket](/fr/parcels/tickets) ou le [rapport de performance](/fr/parcels/performance) lorsque cet élément est affiché.

Les totaux d'expéditions utilisent une fenêtre récente de deux semaines. Les dernières expéditions et les derniers retours sont des listes courtes, pas l'historique complet. Utilisez [Expéditions Colis](/fr/parcels/shipments) lorsque vous devez rechercher sur une période plus longue.

## Tableau de bord Palettes

Ouvrez **Palettes** lorsque vous avez besoin d'une vue d'ensemble de l'activité palettes. Le tableau de bord Palettes peut afficher :

- Les totaux de palettes pour une fenêtre récente de deux semaines
- Les dernières expéditions de palettes
- Les incoming orders
- Les réclamations Palettes
- Les tickets Palettes
- Les résultats de performance et par pays, lorsqu'ils sont disponibles

<Frame caption="Capture d'écran requise — remplacez `/pallet`. Masquez les détails d'entreprise et de destination.">
  <img src="/images/screenshot-placeholder.svg" alt="Espace réservé pour le tableau de bord Palettes" />
</Frame>

De là, vous pouvez ouvrir une commande, continuer vers les [incoming orders](/fr/pallets/incoming-orders) ou la [liste des expéditions](/fr/pallets/shipments), ou suivre une [réclamation](/fr/pallets/claims) ou un [ticket](/fr/pallets/tickets).

Certains comptes administrateur peuvent changer l'entreprise affichée sur le tableau de bord Palettes. Les autres utilisateurs ne voient que leur propre entreprise. Les comptes distributeur peuvent aussi être limités aux pays de destination autorisés.

## Tableau de bord Chargements complets

Ouvrez **Chargements complets** lorsque vous avez besoin d'une vue d'ensemble de l'activité de chargement complet. Le tableau de bord peut afficher :

- Les totaux de transports pour une fenêtre récente de deux semaines
- Les comptes de statut pour Planned, In Transit et Arrived
- Les dernières mises à jour de transport
- La performance sur une période comparée au même intervalle de l'année précédente, lorsque cette vue est affichée

<Frame caption="Capture d'écran requise — remplacez `/ftl`. Masquez l'origine, la destination et les détails d'entreprise.">
  <img src="/images/screenshot-placeholder.svg" alt="Espace réservé pour le tableau de bord Chargements complets" />
</Frame>

De là, vous pouvez ouvrir un [transport](/fr/truckloads/shipments), continuer vers la [liste des expéditions](/fr/truckloads/shipments) ou ouvrir le [rapport de performance](/fr/truckloads/performance) lorsque cet élément est affiché.

## En-tête et compte

Lorsque vous êtes connecté, l'en-tête peut afficher :

- Les modules que votre entreprise est autorisée à utiliser
- Un compteur de notifications non lues
- L'accès à [Account](/fr/start/account), où vous pouvez consulter les informations d'entreprise, mettre à jour votre numéro de téléphone, ouvrir les factures ou les contrats lorsqu'ils sont disponibles, et vous déconnecter

Utilisez le produit qui correspond au type d'expédition. Une réclamation ou un ticket Colis n'apparaîtra pas dans Palettes ou Chargements complets. Une commande palette n'apparaîtra pas dans Colis ou Chargements complets. Un chargement complet n'apparaîtra pas dans Colis ou Palettes.

<Tip>
  Si vous avez besoin d'une expédition précise plutôt que d'une vue d'ensemble, allez à [Rechercher une expédition](/fr/portal/searching).
</Tip>
