Use el restablecimiento de contraseña cuando no pueda iniciar sesión y necesite una contraseña nueva del portal. El flujo tiene tres pasos: solicitar el restablecimiento, introducir el código de su correo y guardar una contraseña nueva.

## Restablezca su contraseña

<Steps>
  <Step title="Abra Forgot password">Desde la [página de inicio de sesión](/es/start/sign-in), seleccione el enlace Forgot password.</Step>
  <Step title="Introduzca su correo electrónico registrado">Pida al portal que envíe un código de restablecimiento a esa dirección.</Step>
  <Step title="Introduzca el código de restablecimiento">Abra el correo y escriba el código en el paso de verificación. El código es válido durante una hora.</Step>
  <Step title="Elija una contraseña nueva">Introduzca la contraseña nueva dos veces. Debe cumplir las reglas de contraseña del portal que aparecen a continuación.</Step>
  <Step title="Inicie sesión de nuevo">Tras un restablecimiento correcto, el portal le devuelve a la página de inicio de sesión. Inicie sesión con la contraseña nueva.</Step>
</Steps>

## Reglas de contraseña

Su contraseña nueva debe incluir todo lo siguiente:

- Al menos 8 caracteres
- Una letra mayúscula
- Una letra minúscula
- Un número
- Un carácter especial permitido: `! @ # $ % ^ & * ) ( + = . _ -`

Los dos campos de contraseña deben coincidir antes de poder guardar la contraseña nueva.

<Warning>
  No envíe a Support su contraseña, el código de restablecimiento ni una captura de la verificación del correo. Si el código ha caducado, inicie el restablecimiento de nuevo desde la página de inicio de sesión.
</Warning>

## Si el restablecimiento no funciona

1. Confirme que está usando el correo electrónico registrado para el portal.
2. Revise las carpetas de correo no deseado o spam para el correo de restablecimiento.
3. Solicite un código nuevo si ha pasado más de una hora.
4. Siga [No puedo iniciar sesión](/es/support/cannot-sign-in) si aún no puede acceder al portal.
