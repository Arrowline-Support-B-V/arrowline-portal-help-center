Der Performance-Bericht für Pakete ist eine Seite in Pakete nach der Anmeldung. Er gilt für einen Berichtszeitraum, nicht für eine einzelne Sendung.

<Frame caption="Screenshot erforderlich — ersetzen Sie `/report/detail` mit sichtbarem gewähltem Zeitraum. Blenden Sie Unternehmensnamen aus.">
  <img src="/images/screenshot-placeholder.svg" alt="Platzhalter für den Performance-Bericht von Pakete" />
</Frame>

## Den Bericht öffnen

<Steps>
  <Step title="Öffnen Sie Pakete">Melden Sie sich an und öffnen Sie den Arbeitsbereich Pakete.</Step>
  <Step title="Öffnen Sie den Performance-Bericht">Nutzen Sie den Bericht vom Dashboard von Pakete, wenn er angezeigt wird.</Step>
  <Step title="Wählen Sie den Zeitraum">Setzen Sie das Datum oder den Monat, den Sie prüfen möchten.</Step>
  <Step title="Lesen Sie die Ergebnisse">Prüfen Sie die Statussummen, Performance-Karten, das Diagramm und die Ländertabelle.</Step>
  <Step title="Laden Sie ein PDF herunter">Exportieren Sie den Bericht, der auf dem Bildschirm steht, einschließlich des gewählten Zeitraums.</Step>
</Steps>

Der Bericht braucht das Modul Pakete. Wenn Sie ihn nicht öffnen können, hat Ihr Unternehmen diese Seite möglicherweise nicht.

<Info>
  Nutzen Sie [Sendungen in Pakete](/de/parcels/shipments), wenn Sie einen einzelnen Auftrag brauchen. Dieser Bericht gilt für einen Zeitraum, nicht für eine einzelne Paketsendung.
</Info>
