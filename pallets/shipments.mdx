The pallet shipment list is the signed-in working list for pallet movements. Use it when you already have an order number or barcode.

<Frame caption="Screenshot required — replace `/pallet-shipments`. Mask shipper and destination.">
  <img src="/images/screenshot-placeholder.svg" alt="Placeholder for the pallet shipment list" />
</Frame>

## What you can do

- Filter by date, status, shipper or destination
- Sort and move through pages
- Open the order or package
- Turn status notifications on or off
- Download a shipping label when the action is shown

## Columns on the list

Each row can include:

- Order date
- Order number
- Barcode
- Shipper
- Destination
- Status
- Notification controls
- Shipping-label action

An order can have more than one barcode. Confirm both the order number and the barcode before you continue.

## Find a pallet

<Steps>
  <Step title="Open Pallets">Sign in and open the Pallets workspace.</Step>
  <Step title="Open the shipment list">Go to the pallet shipment list.</Step>
  <Step title="Set the filters">Use date, status, shipper or destination, together with the order number or barcode.</Step>
  <Step title="Open the record">Open the order for the whole shipment, or the package for one barcode.</Step>
</Steps>

Distributor accounts may only see destinations they are allowed to work with.

<Info>
  If you only need progress and do not have a login, use [Track a pallet without signing in](/pallets/public-tracking).
</Info>
