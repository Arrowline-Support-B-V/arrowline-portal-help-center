O relatório de desempenho Cargas completas é uma página Cargas completas com sessão iniciada. Serve para um período de relatório, não para um único transporte.

## Abrir o relatório

<Steps>
  <Step title="Abrir Cargas completas">Inicie sessão e abra o espaço de trabalho Cargas completas.</Step>
  <Step title="Abrir o relatório de desempenho">Utilize o relatório a partir do painel Cargas completas quando for apresentado.</Step>
  <Step title="Escolher o período">Defina o intervalo de datas que pretende consultar.</Step>
  <Step title="Restringir o âmbito">Utilize os filtros de origem, destino ou outros filtros apresentados na página. Um filtro de cliente aparece apenas para algumas contas de administrador.</Step>
  <Step title="Ler os resultados">Verifique os totais, as tabelas por país ou por rota e os transportes agrupados.</Step>
  <Step title="Exportar">Exporte o relatório que está no ecrã, incluindo os filtros ativos.</Step>
</Steps>

O relatório precisa do módulo Cargas completas. Se não o conseguir abrir, a sua empresa pode não ter essa página.

<Info>
  Utilize [Envios Cargas completas](/pt/truckloads/shipments) quando precisar de um transporte individual. Este relatório é para um período, não para uma carga completa.
</Info>
