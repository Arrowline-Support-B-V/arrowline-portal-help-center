Utilisez la réinitialisation du mot de passe lorsque vous ne pouvez pas vous connecter et que vous avez besoin d'un nouveau mot de passe du portail. Le flux comporte trois étapes : demander une réinitialisation, saisir le code reçu par e-mail, puis enregistrer un nouveau mot de passe.

## Réinitialiser votre mot de passe

<Steps>
  <Step title="Ouvrez Forgot password">Depuis la [page Sign in](/fr/start/sign-in), sélectionnez le lien Forgot password.</Step>
  <Step title="Saisissez votre e-mail enregistré">Demandez au portail d'envoyer un code de réinitialisation à cette adresse.</Step>
  <Step title="Saisissez le code de réinitialisation">Ouvrez l'e-mail et saisissez le code à l'étape de vérification. Le code est valable une heure.</Step>
  <Step title="Choisissez un nouveau mot de passe">Saisissez le nouveau mot de passe deux fois. Il doit respecter les règles de mot de passe du portail ci-dessous.</Step>
  <Step title="Connectez-vous à nouveau">Après une réinitialisation réussie, le portail vous ramène à la page Sign in. Connectez-vous avec le nouveau mot de passe.</Step>
</Steps>

## Règles de mot de passe

Votre nouveau mot de passe doit inclure tous les éléments suivants :

- Au moins 8 caractères
- Une lettre majuscule
- Une lettre minuscule
- Un chiffre
- Un caractère spécial autorisé : `! @ # $ % ^ & * ) ( + = . _ -`

Les deux champs de mot de passe doivent correspondre avant que vous puissiez enregistrer le nouveau mot de passe.

<Warning>
  N'envoyez pas votre mot de passe, votre code de réinitialisation ni une capture d'écran de vérification d'e-mail à Support. Si le code a expiré, recommencez la réinitialisation depuis la page Sign in.
</Warning>

## Si la réinitialisation ne fonctionne pas

1. Vérifiez que vous utilisez l'adresse e-mail enregistrée pour le portail.
2. Consultez les dossiers spam ou courrier indésirable pour l'e-mail de réinitialisation.
3. Demandez un nouveau code si plus d'une heure s'est écoulée.
4. Suivez [Je ne peux pas me connecter](/fr/support/cannot-sign-in) si vous n'arrivez toujours pas à accéder au portail.
