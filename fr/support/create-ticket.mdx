Créez le ticket dans le même produit que l'expédition. Un ticket Colis n'apparaîtra pas dans Palettes. Chargements complets n'a pas de formulaire de ticket dans le portail. Pour un chargement complet, [contactez Support](/fr/support/contact) avec les détails du transport.

<Frame caption="Capture d'écran requise — remplacez `/tickets/add` ou `/pallet/tickets/add`. Masquez les identifiants.">
  <img src="/images/screenshot-placeholder.svg" alt="Espace réservé pour le formulaire de création de ticket" />
</Frame>

<Steps>
  <Step title="Ouvrez le module concerné">Choisissez Colis ou Palettes. Ne mélangez pas les deux. N'utilisez pas ces formulaires pour un chargement complet.</Step>
  <Step title="Ouvrez Tickets">Sélectionnez la liste des tickets et commencez un nouveau ticket.</Step>
  <Step title="Recherchez la commande">Saisissez le numéro de commande complet. Le portail bloque une commande inconnue.</Step>
  <Step title="Sélectionnez les codes-barres">Choisissez au moins un numéro track and trace de colis ou un code-barres palette.</Step>
  <Step title="Choisissez le type de problème">Sélectionnez une catégorie puis une sous-catégorie.</Step>
  <Step title="Décrivez et envoyez">Écrivez un commentaire, joignez des fichiers si besoin et envoyez une seule fois. Les fichiers Colis peuvent aller jusqu'à 50 Mo chacun.</Step>
</Steps>

Si chaque code-barres de la commande a déjà un ticket, ouvrez plutôt ce ticket.

Pour les étapes produit complètes, voir [Tickets Colis](/fr/parcels/tickets) ou [Tickets Palettes](/fr/pallets/tickets). Pour un dommage, un manquant ou une perte, utilisez une réclamation, pas un second ticket.
