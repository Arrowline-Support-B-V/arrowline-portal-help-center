Le rapport de performance Colis est une page Colis une fois connecté. Il concerne une période de reporting, pas une seule expédition.

<Frame caption="Capture d'écran requise — remplacez `/report/detail` avec la période sélectionnée visible. Masquez les noms d'entreprise.">
  <img src="/images/screenshot-placeholder.svg" alt="Espace réservé pour le rapport de performance Colis" />
</Frame>

## Ouvrir le rapport

<Steps>
  <Step title="Ouvrez Colis">Connectez-vous et ouvrez l'espace de travail Colis.</Step>
  <Step title="Ouvrez le rapport de performance">Utilisez le rapport depuis le tableau de bord Colis lorsqu'il est affiché.</Step>
  <Step title="Choisissez la période">Définissez la date ou le mois que vous voulez consulter.</Step>
  <Step title="Lisez les résultats">Vérifiez les totaux de statut, les cartes de performance, le graphique et le tableau par pays.</Step>
  <Step title="Téléchargez un PDF">Exportez le rapport affiché à l'écran, y compris la période sélectionnée.</Step>
</Steps>

Le rapport nécessite le module Colis. Si vous ne pouvez pas l'ouvrir, votre entreprise n'a peut-être pas cette page.

<Info>
  Utilisez [Expéditions Colis](/fr/parcels/shipments) lorsque vous avez besoin d'une commande individuelle. Ce rapport concerne une période, pas un seul colis.
</Info>
