## Wo Sie beginnen

Das Dashboard von Pakete ist der Überblick. Es kann aktuelle Sendungssummen, neueste Sendungen, neueste Retouren, offene Claims, offene Tickets und eine Servicelevel-Zusammenfassung zeigen. Siehe [Das Dashboard verstehen](/de/start/dashboard).

Vom Dashboard aus können Sie öffnen:

- Die [Sendungsliste](/de/parcels/shipments)
- Eine [Retoure](/de/parcels/returns)
- Einen [Claim](/de/parcels/claims) oder ein [Ticket](/de/parcels/tickets)
- Den [Performance-Bericht](/de/parcels/performance) für einen gewählten Zeitraum, wenn dieser Bericht angezeigt wird

<Info>
  Sie können im Portal keine Sendung anlegen. Wenn eine Paketsendung fehlt, prüfen Sie zuerst Auftragsnummer und Datumsbereich. Folgen Sie danach [Eine Sendung wird nicht gefunden](/de/support/shipment-not-found).
</Info>
