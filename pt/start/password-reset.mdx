Utilize a reposição da palavra-passe quando não conseguir iniciar sessão e precisar de uma nova palavra-passe do portal. O fluxo tem três passos: pedir uma reposição, introduzir o código do e-mail e, em seguida, guardar uma nova palavra-passe.

## Redefinir a palavra-passe

<Steps>
  <Step title="Abrir Forgot password">Na [página de início de sessão](/pt/start/sign-in), selecione a ligação Forgot password.</Step>
  <Step title="Introduzir o e-mail registado">Peça ao portal que envie um código de reposição para esse endereço.</Step>
  <Step title="Introduzir o código de reposição">Abra o e-mail e escreva o código no passo de verificação. O código é válido durante uma hora.</Step>
  <Step title="Escolher uma nova palavra-passe">Introduza a nova palavra-passe duas vezes. Tem de cumprir as regras de palavra-passe do portal abaixo.</Step>
  <Step title="Iniciar sessão novamente">Depois de uma reposição bem-sucedida, o portal devolve-o à página de início de sessão. Inicie sessão com a nova palavra-passe.</Step>
</Steps>

## Regras da palavra-passe

A nova palavra-passe tem de incluir tudo o seguinte:

- Pelo menos 8 caracteres
- Uma letra maiúscula
- Uma letra minúscula
- Um número
- Um carácter especial permitido: `! @ # $ % ^ & * ) ( + = . _ -`

Os dois campos de palavra-passe têm de coincidir antes de poder guardar a nova palavra-passe.

<Warning>
  Não envie a palavra-passe, o código de reposição nem uma captura de ecrã da verificação por e-mail à Support. Se o código tiver expirado, recomece a reposição a partir da página de início de sessão.
</Warning>

## Se a reposição não funcionar

1. Confirme que está a utilizar o endereço de e-mail registado no portal.
2. Verifique as pastas de spam ou de lixo eletrónico para encontrar o e-mail de reposição.
3. Peça um novo código se tiver passado mais de uma hora.
4. Siga [Não consigo iniciar sessão](/pt/support/cannot-sign-in) se ainda não conseguir aceder ao portal.
