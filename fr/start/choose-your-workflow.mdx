L'Arrowline Portal est organisé selon le travail que votre entreprise est autorisée à effectuer. Après la connexion, l'adresse d'accueil du portail n'est pas un tableau de bord mixte. Elle vous envoie vers le premier module que votre entreprise peut utiliser.

## Espaces de travail une fois connecté

<CardGroup cols={2}>
  <Card title="Colis" icon="box" href="/fr/parcels/overview">

  </Card>
  <Card title="Palettes" icon="boxes-stacked" href="/fr/pallets/overview">
    Utilisez Palettes pour les commandes incoming, les expéditions de palettes, les détails de colis, les réclamations et les tickets Palettes.

  <Card title="Chargements complets" icon="truck" href="/fr/truckloads/overview">
    Utilisez Chargements complets pour les transports en chargement complet, les arrêts, les alertes de statut et le rapport de performance.
  </Card>
</CardGroup>

## Ce qui s'ouvre après la connexion

Le portail lit les modules attribués à votre entreprise et ouvre le premier espace de travail disponible dans cet ordre :

1. Colis
2. Chargements complets, si votre entreprise l'a
3. Palettes

La navigation supérieure n'affiche que les modules auxquels votre entreprise a droit. Vous ne pouvez pas non plus ouvrir un module masqué avec un lien enregistré.

</Warning>

## Suivre une palette sans se connecter

Le suivi public des palettes est une page distincte. Toute personne disposant d'un numéro de commande ou d'un numéro de suivi peut [suivre une palette](/fr/pallets/public-tracking) sans compte portail.

Les expéditions de colis et les transports Chargements complets ne sont pas disponibles sur la page de suivi public. Utilisez l'espace de travail Colis ou Chargements complets une fois connecté pour ceux-ci.
