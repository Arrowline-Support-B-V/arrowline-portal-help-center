## Follow a parcel

<Steps>
  <Step title="Open Parcels">From the dashboard, open the Parcels workspace.</Step>
  <Step title="Open the shipment list">Go to the parcel shipment list.</Step>
  <Step title="Find the order">Search by the complete order number. Widen the date range if needed.</Step>
  <Step title="Read the latest status">Check the grouped status and the track-and-trace value on the row.</Step>
  <Step title="Inspect the shipment">Open the record if you need more of the information shown for that parcel.</Step>
</Steps>

The portal can only show events it has received. A pause between updates does not always mean the parcel has stopped moving.

## If the status is not what you expected

- Confirm the order number and date
- Check whether a later event has arrived
- See [Parcel statuses](/parcels/statuses)
- If the status is in the exceptions group, follow [Delivery exceptions](/parcels/delivery-exceptions)
- If the latest event is missing, follow [A shipment status is not updated](/support/status-not-updated)

<Warning>
  A tracking status is not a claim or ticket result. Open one claim or one ticket only when you need Support to act.
</Warning>
