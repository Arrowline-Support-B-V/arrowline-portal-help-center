Die Sendungsliste von Pakete nach der Anmeldung ist der Hauptort, um eine ausgehende Paketsendung zu prüfen. Das Portal nutzt keine eigene öffentliche Verfolgungsseite für Pakete.

<Frame caption="Screenshot erforderlich — ersetzen Sie eine geprüfte Zeile unter `/shipments`. Blenden Sie Namen und Adressen aus.">
  <img src="/images/screenshot-placeholder.svg" alt="Platzhalter für Angaben zu einer Paketsendung" />
</Frame>

## Was Sie prüfen

Bestätigen Sie in der Liste:

1. Auftragsnummer
2. Kunde und Bestimmungsort
3. Track-and-trace-Wert
4. Frachtführer
5. Bestelldatum
6. Letzter Status

Öffnen Sie die Sendung aus der Liste, wenn Sie den ausgewählten Datensatz prüfen müssen. Nutzen Sie nur die Informationen, die das Portal zeigt. Gehen Sie nicht von Absender-, Empfänger- oder Liefernachweisdetails aus, wenn sie nicht auf dem Bildschirm stehen.

## Zugehörige Datensätze in Pakete

| Wenn Sie brauchen | Öffnen Sie |
| --- | --- |
| Eine Retoure | [Retouren in Pakete](/de/parcels/returns) |
| Den letzten gruppierten Status | [Status in Pakete](/de/parcels/statuses) |
| Eine Verzögerung oder Ausnahme | [Lieferausnahmen](/de/parcels/delivery-exceptions) |
| Einen formellen Vorfall | [Claims in Pakete](/de/parcels/claims) |
| Eine Untersuchung | [Tickets in Pakete](/de/parcels/tickets) |

<Tip>
  Halten Sie Auftragsnummer und track-and-trace-Wert bereit, bevor Sie Support kontaktieren. Siehe [Angaben, die Support braucht](/de/support/required-information).
</Tip>
